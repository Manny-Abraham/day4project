# Emotion Movie Recommender

Ubiquitous language for emotion-to-movie matching in this spec map.

## Language

**Current feeling**:
Free-text state the viewer reports now, optional, used for tone only.
_Avoid_: current emotion, mood now

**Desired feeling**:
Target state the viewer wants to reach, required, normalized to one tag for filtering.
_Avoid_: desired emotion, target mood

**Emotion tag**:
One of the fixed 8 filter values: Happy, Sad, Stressed, Angry, Bored, Lonely, Excited, Tired/Relaxed.
_Avoid_: feeling label, mood tag
